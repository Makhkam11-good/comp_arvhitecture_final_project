# ShopApp

ShopApp - Spring Boot проект интернет-магазина.

## Стек технологий

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- Spring Validation
- PostgreSQL
- Lombok
- JJWT
- Springdoc OpenAPI
- Maven

## Команда

- Махкамбек
- Шохруз
- Иброхим

## Запуск проекта

Перед запуском установите Java 17 и PostgreSQL.

Создайте базу данных:

```sql
CREATE DATABASE shopapp_db;
```

Запустите приложение:

```bash
mvn spring-boot:run
```

Приложение будет доступно на порту `8080`.
